# RobloxUnlocker

Скрипт для Windows, который возвращает загрузку моделей, текстур и аватаров в Roblox, если они остаются серыми или грузятся бесконечно.

## Проблема

Roblox качает ассеты по QUIC (HTTP/3, UDP 443). У части провайдеров этот протокол ломается: соединение устанавливается, но данные не идут. Клиент не переключается на обычный TCP и ждёт по 60 секунд на каждый файл — в итоге модели, одежда и иконки не появляются.

Поэтому «разблокировка Roblox» (VPN, zapret, смена DNS) может не помочь: домены доступны, а сломан именно транспорт. Вторая, независимая причина — мёртвые адреса CDN в ответе DNS, из-за которых не грузятся картинки.

Скрипт делает две вещи:

1. Запрещает Roblox использовать QUIC — клиент уходит на TCP, и ассеты начинают качаться.
2. Подбирает живые адреса CDN и закрепляет их в `hosts`.

## Кому подойдёт

| Ситуация | Подойдёт |
|---|---|
| Модели, текстуры, звуки серые или не прогружаются | да |
| Аватары без одежды и аксессуаров | да |
| Не грузятся иконки, превью, картинки в меню | да |
| Через VPN всё работает, без VPN — нет | да |
| Roblox не запускается, не входит в аккаунт, не подключается к игре | нет, нужен обход блокировок |
| Лаги, низкий FPS, проблемы со звуком | нет |

## Проверить, нужен ли он тебе

Нужны Windows 10/11 и 2 минуты. Права администратора на этом шаге не требуются.

1. Скачай репозиторий:

```bat
git clone https://github.com/StandarterDF/RobloxUnlocker.git
cd RobloxUnlocker
```

Можно и без git: **Code → Download ZIP**, распаковать.

2. Запусти Roblox, зайди в игру, где ассеты не грузятся, поиграй 2–3 минуты и закрой его.

3. Открой `service.bat` и выбери **3** (диагностика).

В конце будет строка `ВЕРДИКТ: ...`:

| Вердикт | Что значит |
|---|---|
| `ФИКС НУЖЕН` | проблема найдена, можно ставить |
| `ФИКС НЕ НУЖЕН` | признаков нет, ничего делать не нужно |
| `НЕДОСТАТОЧНО ДАННЫХ` | мало данных, поиграй подольше и повтори |
| `УЖЕ РАБОТАЕТ` | фикс уже стоит и работает |
| `НУЖНО ОБНОВИТЬ HOSTS` | QUIC уже отключён, осталось обновить адреса CDN |
| `ЭТОТ ФИКС НЕ ПОМОГ` | проблема не в QUIC/CDN, нужен другой инструмент |

## Установка

```bat
service.bat  ->  1
```

Скрипт сам запросит права администратора. После установки полностью закрой Roblox и запусти заново.

## Проверка после установки

`service.bat` → **2**. В блоке «Последняя сессия Roblox» должно быть `0` зависаний и `0` ошибок ассетов, а модели в игре — на месте.

## Что именно меняется

- Правила файрвола Windows: исходящий UDP 443 → Block для `RobloxPlayerBeta.exe` и `RobloxStudioBeta.exe`.
- Управляемый блок в `hosts` между маркерами `# >>> RobloxUnlocker >>>` / `# <<< RobloxUnlocker <<<` (перед изменением делается резервная копия).
- Задача планировщика `RobloxUnlocker-Refresh`: раз в 30 минут добавляет правило на новую версию Roblox, раз в 3 дня обновляет `hosts`.

Политики файрвола по умолчанию не меняются, другие программы не затрагиваются.

## Удаление

`service.bat` → **9**. Всё возвращается в исходное состояние, резервные копии `hosts` остаются в `C:\ProgramData\RobloxUnlocker\`.

## Готовый промт

Скопируй это в нейросеть-агента, у которой есть доступ к терминалу на твоём ПК (OpenCode, Codex, Claude Code и т.п.). Он сам проверит, нужен ли фикс, и поставит его только при необходимости.

```text
Ты работаешь на моём Windows-ПК и можешь выполнять команды в PowerShell.
Задача: проверить, поможет ли мне RobloxUnlocker, и установить его только
если диагностика покажет, что проблема именно в этом.

Контекст: в Roblox не грузятся модели, текстуры или аватары (серые).
Репозиторий: https://github.com/StandarterDF/RobloxUnlocker

Правила:
- Ничего не меняй в системе до окончания диагностики.
- Не трогай сторонние записи в hosts, не отключай антивирус и файрвол,
  не устанавливай VPN, не меняй DNS и не правь реестр.
- Все команды выполняй в папке репозитория, не в системном temp.
- После каждого шага показывай мне, что получилось.

Шаги:
1. Проверь, что это Windows 10/11 и что доступен PowerShell.
2. Скачай репозиторий в C:\Users\<мой пользователь>\RobloxUnlocker:
   git clone https://github.com/StandarterDF/RobloxUnlocker.git C:\Users\<мой пользователь>\RobloxUnlocker
   Если git нет — скачай ZIP с https://github.com/StandarterDF/RobloxUnlocker
   (кнопка Code -> Download ZIP), распакуй и переименуй папку
   RobloxUnlocker-main в RobloxUnlocker.
   Все дальнейшие команды выполняй из этой папки.
3. Скажи мне запустить Roblox, зайти в проблемную игру на 2-3 минуты
   и полностью закрыть клиент. Дождись подтверждения.
4. Запусти диагностику без прав администратора:
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts\diagnose.ps1
5. Найди в выводе строку "ВЕРДИКТ:" и действуй по ней:
   - "ФИКС НУЖЕН" -> переходи к шагу 6;
   - "ФИКС НЕ НУЖЕН" или "НЕДОСТАТОЧНО ДАННЫХ" -> ничего не устанавливай,
     объясни почему и что ещё можно проверить;
   - "УЖЕ РАБОТАЕТ" -> ничего не делай, только подтверди;
   - "НУЖНО ОБНОВИТЬ HOSTS" -> выполни только:
     powershell -ExecutionPolicy Bypass -File scripts\hosts.ps1 -Mode apply
   - "ЭТОТ ФИКС НЕ ПОМОГ" -> предложи откат и объясни, что нужен обход
     блокировок (VPN/zapret), сам ничего не устанавливай.
6. Установи фикс с правами администратора (будет запрос UAC):
   powershell -ExecutionPolicy Bypass -File scripts\install.ps1
7. Попроси меня полностью закрыть все процессы Roblox и запустить игру
   заново. Дождись, пока я поиграю 5-10 минут.
8. Проверь результат:
   - powershell -ExecutionPolicy Bypass -File scripts\status.ps1
   - сравни число зависаний и ошибок ассетов с тем, что было до установки;
9. Если зависаний не стало меньше — откати изменения:
   powershell -ExecutionPolicy Bypass -File scripts\uninstall.ps1
   и скажи, что фикс не подошёл.

В конце дай короткий отчёт: вердикт диагностики, что установлено, цифры
до и после, что делать дальше. Не приукрашивай: если не помогло — так и скажи.
```
